# Investigator portraits

The 24 PNGs in this folder are byte-for-byte copies of files directly inside `TopExpertUnity/Assets/Investigators/` at Git commit `74b4fb175f668094d1efc0b1617b71dc29a9f99e`. Subfolders (including AI variants) and Unity metadata were excluded. Red is absent from that exact tree and was not added.

`portraits.json` lists the displayed filenames and names. Test Setup lists all portraits. Its per-case selection determines the Test tray and starting test roster; viewing the tray does not change assignments or game state.
